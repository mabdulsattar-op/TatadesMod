Tatade's Mod - Fabric client anticheat test mod

This project targets Minecraft 1.21.11 (client-only) and Java 21.

Quick build:
1. Install Gradle 8+ or generate Gradle wrapper on a machine that has Gradle.
2. From project root run: gradle wrapper
3. Then run: ./gradlew build  (on Windows: gradlew.bat build)

Notes:
- The environment in this session did not have Gradle installed, so the wrapper was not generated automatically.
- If you want me to attempt generating a portable wrapper (download + run), allow network download in this environment and I'll try to create a working gradlew.bat and gradle-wrapper.jar.

Output JAR will be at: build/libs/tatadesmod-1.0.0.jar
